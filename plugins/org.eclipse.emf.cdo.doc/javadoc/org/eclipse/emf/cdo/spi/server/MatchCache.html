Interface MatchCache

public interface MatchCache
Caches boolean results of matcher evaluations.

Implementations must be thread-safe. A null result from get(Object) means that the key is not cached; Boolean.TRUE and Boolean.FALSE represent cached matches and non-matches, respectively.
