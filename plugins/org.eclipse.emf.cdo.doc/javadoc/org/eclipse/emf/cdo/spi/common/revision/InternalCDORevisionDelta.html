Interface InternalCDORevisionDelta

All Superinterfaces:
CDOBranchAdjustable, CDOBranchProvider, CDOBranchVersion, CDOIDAndVersion, CDOIdentifiable, CDOReferenceAdjustable, CDORevisionDelta, CDORevisionKey, CDOVersionProvider
public interface InternalCDORevisionDelta extends CDORevisionDelta, CDOReferenceAdjustable, CDOBranchAdjustable
Mutable internal form of a revision delta used while building, applying, and rebasing changes to one object. It retains the feature changes and the branch/version context required to apply them to a target revision.

2.0
