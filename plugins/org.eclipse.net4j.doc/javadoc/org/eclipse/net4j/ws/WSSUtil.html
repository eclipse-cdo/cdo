Class WSSUtil

java.lang.Object
org.eclipse.net4j.ws.WSSUtil
public final class WSSUtil extends Object
Creates and describes secure WebSocket (WSS) connector and acceptor products.

WSS uses the same Net4j framing, provider selection, and connector ownership contracts as WS. The selected provider remains responsible for TLS and WebSocket transport details.

    • prepareContainer

      @Deprecated public static void prepareContainer(org.eclipse.net4j.util.container.IManagedContainer container)
      Deprecated.
      Initialized containers are prepared automatically.
      Manually prepares a raw container with the WSS acceptor and connector factories. Initialized containers receive these factories automatically through declarative container initialization. Manual preparation remains appropriate for containers created with ContainerUtil.createContainer().
