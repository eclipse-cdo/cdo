Interface SQLFragmentStep

public interface SQLFragmentStep
A structured fragment builder. Raw SQL text is trusted input and is not parsed; identifiers and parameters are represented as separate structured parts so the compiler can quote identifiers and track parameter occurrences. Prefer structured expressions for operators and explicitly group a fragment expression when its internal precedence matters.

    • sql

      SQLFragmentStep sql(String trustedSQL)
      Appends trusted SQL text to the fragment. Raw text is not parsed and must not contain ?, even inside a quoted SQL literal. Represent every JDBC parameter placeholder with SQL.param() or a structured fragment parameter token. Generated literals such as SQL.literal("?") are separate structured expressions and are allowed. This restriction keeps positional and identity-based JDBC binding reliable.
      Parameters:
      trustedSQL - trusted SQL text, supplied as a literal
      Returns:
      the next valid fluent stage

      4.15
