public static class PermissionCacheFactory.Default extends PermissionCacheFactory
Built-in bounded, LRU-like permission-cache creator factory.

Its configured capacity limits the creator-wide backing store; it is not a separate capacity for every repository, user, or branch. The returned logical cache generations remain isolated by their repository/user/ branch scope even though the backing store is shared. The default capacity is 100000. A configured capacity that is not a positive integer causes product creation, and therefore repository startup, to fail.
