Package org.eclipse.net4j.db.dml

Interface SQLStatement

public interface SQLStatement
An immutable adapter-compiled statement definition. Each call to prepare(IDBConnection, ReuseProbability) obtains a statement from the connection's existing cache; the returned statement remains caller-owned and must be released using the normal Net4j DB lifecycle. This definition retains neither connection nor statement.

    • bind

      void bind(PreparedStatement stmt, Object... values) throws SQLException
      Binds positional values in placeholder order. Positions are JDBC's one-based positions, and the argument count must exactly match the placeholder count. Repeated logical parameter identities occupy a position for every occurrence. Each value uses its parameter's converter, if any, followed by default JDBC binding; NULL uses an explicit JDBC type or inferred field type. An unresolved NULL requires an explicit type or specialized binder. If a later conversion or JDBC setter fails, earlier positions may already have been changed; binding is not atomic.
      Parameters:
      stmt - the JDBC statement
      values - values in placeholder order
      Throws:
      SQLException - if JDBC binding fails
      IllegalArgumentException - if the value count differs from the placeholder count
      NullPointerException - if stmt or values is null

    • bindParameter

      void bindParameter(PreparedStatement stmt, int index, Object value) throws SQLException
      Binds one value at a one-based placeholder index. Default binding applies parameter conversion to non-null values and uses explicit JDBC type before inferred field type for NULL. A failed operation leaves existing bindings untouched except for effects already made by JDBC.
      Parameters:
      stmt - the JDBC statement
      index - the one-based placeholder index
      value - the application value
      Throws:
      SQLException - if JDBC binding fails
      IllegalArgumentException - if index is outside the compiled parameter range
      NullPointerException - if stmt is null

    • bindParameter

      void bindParameter(PreparedStatement stmt, SQLParameter parameter, Object value) throws SQLException
      Binds a logical parameter identity at every occurrence in generated SQL order. Matching uses object identity. Each occurrence keeps its own inferred field type; a failure at a later occurrence can leave earlier occurrences bound.
      Parameters:
      stmt - the JDBC statement
      parameter - the identity returned by a particular SQL.param() call
      value - the application value to bind at each occurrence
      Throws:
      SQLException - if JDBC binding fails
      IllegalArgumentException - if the parameter identity is absent from this statement
      NullPointerException - if a required argument is null
