    • compile

      default SQLStatement compile(IDBAdapter adapter)
      Compiles this complete definition for an adapter, rendering adapter-specific identifier quoting and recording parameter occurrences in generated SQL order. The returned statement can be prepared through an IDBConnection and bound through its positional or parameter-identity methods.

      adapter - the database adapter for identifier quoting and NULL type mapping
      Returns:
      the compiled statement
