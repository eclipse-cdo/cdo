Callable<Object>, CDOBranchProvider, CDOCommitContext, CDOIDProvider, InternalCDOTransaction.InternalCDOCommitContext

InternalCDOXATransaction
public static interface InternalCDOXATransaction.InternalCDOXACommitContext extends Callable<Object>, CDOIDProvider, InternalCDOTransaction.InternalCDOCommitContext
Per-operation state passed through an XA commit. It gathers the participating transactions' requested object IDs, carries the protocol result, and invokes the state-specific work that advances or rolls back the coordinated commit.
