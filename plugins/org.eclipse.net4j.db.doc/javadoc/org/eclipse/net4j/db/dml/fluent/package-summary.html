Package org.eclipse.net4j.db.dml.fluent

package org.eclipse.net4j.db.dml.fluent
Staged fluent builders for SQL data manipulation. Each builder operation returns the stage that permits the next valid clause; incomplete assignments and joins therefore cannot be built or compiled through the public type signatures. Complete stages expose SQLBuildStep.build() for an immutable adapter-neutral snapshot and SQLBuildStep.compile(org.eclipse.net4j.db.IDBAdapter) for direct adapter-specific compilation. Builder stages are mutable construction cursors: reuse a retained stage only while it remains current, and keep a previously returned template as the stable statement definition.
