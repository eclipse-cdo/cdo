public static interface SchedulingConnector.IScheduler

    • complete

      boolean complete(InternalChannel channel, boolean bufferCompleted)
      Completes or retains the current channel after a send attempt. An incomplete buffer remains selected so a transport can resume it without interleaving another channel's buffer. After a successful completion, the connector requests another send attempt if any channel remains scheduled. This request must be asynchronous so it cannot send reentrantly from the completion callback.
      Parameters:
      channel - the channel that was selected
      bufferCompleted - true only after the complete buffer was transmitted successfully
      Returns:
      true if the completion was for the current channel and at least one channel remains scheduled
