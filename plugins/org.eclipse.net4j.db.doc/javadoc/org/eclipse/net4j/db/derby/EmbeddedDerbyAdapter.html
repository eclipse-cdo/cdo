    • getDatabaseProductNames

      public String[] getDatabaseProductNames()
      Description copied from interface: IDBAdapter
      Returns the JDBC database product names recognized by this adapter. Product names are trimmed and compared case-insensitively. The default recognizes the adapter's declared name. Implementations may return additional aliases.
      Returns:
      the exact JDBC product names recognized by this adapter

    • getDatabaseURLPattern

      public String getDatabaseURLPattern()
      Description copied from interface: IDBAdapter
      Returns an optional regular expression that constrains JDBC URL matching. The complete URL must match case-insensitively; a missing URL does not match.
      Returns:
      a JDBC URL regular expression, or null if no URL constraint applies
