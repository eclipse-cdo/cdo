Net4j DB Adapters

Identifier:
org.eclipse.net4j.db.dbAdapters

Since:
[Enter the first release in which this extension point appears.]

Description:
Contributes database adapters to the Net4j DB registry. Recognition metadata is read from the contribution before its adapter class is instantiated, so JDBC connections can be matched lazily from database product names and optional driver-name and URL constraints. A product name must match an exact name or product-name pattern, and every configured driver-name and URL constraint must also match.

Configuration Markup:

<!ELEMENT extension (dbAdapter+)>

<!ATTLIST extension

point CDATA #REQUIRED

id    CDATA #IMPLIED

name  CDATA #IMPLIED>


<!ELEMENT dbAdapter EMPTY>

<!ATTLIST dbAdapter

name               CDATA #REQUIRED

version            CDATA #REQUIRED

class              CDATA #REQUIRED

productNames       CDATA #IMPLIED

productNamePattern CDATA #IMPLIED

driverNamePattern  CDATA #IMPLIED

urlPattern         CDATA #IMPLIED>

  • name -
  • version -
  • class -
  • productNames - Comma-separated exact JDBC database product names. Names are trimmed and matched case-insensitively. If omitted, the adapter's declared name is used. Use productNamePattern for product names that contain commas.
  • productNamePattern - Optional Java regular expression matched case-insensitively against the complete trimmed JDBC product name. It supplements the exact productNames matches.
  • driverNamePattern - Optional Java regular expression matched case-insensitively against the complete trimmed JDBC driver name. When present, the driver name must be available and match.
  • urlPattern - Optional Java regular expression matched case-insensitively against the complete trimmed JDBC URL. When present, the URL must be available and match.
