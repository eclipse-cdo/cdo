public abstract class AbstractChangeSetsConflictResolver extends AbstractConflictResolver implements CDOConflictResolver.NonConflictAware
Base for resolvers that compare a transaction's local change set with change sets received through session invalidations. It tracks transaction edits and queues relevant remote invalidations so subclasses can merge changes against the transaction's clean revisions and reset that tracking after commit or rollback.
