public static class CDOAutoLocker.ForSingleValuedChanges extends CDOAutoLocker
An auto locker that only locks objects when their single-valued features are changed.

This auto locker is useful in combination with a conflict resolver that is able to automatically resolve possible conflicts in many-valued features, such as CDOMergingConflictResolver.
