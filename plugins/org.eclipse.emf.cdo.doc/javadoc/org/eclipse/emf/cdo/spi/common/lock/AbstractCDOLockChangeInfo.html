public abstract class AbstractCDOLockChangeInfo extends org.eclipse.net4j.util.event.Event implements CDOLockChangeInfo
Shared event implementation for lock notifications backed by a set of lock deltas. It derives the affected IDs, lock types, and lock/unlock operations from those deltas so listeners can summarize a batch of lock changes.
