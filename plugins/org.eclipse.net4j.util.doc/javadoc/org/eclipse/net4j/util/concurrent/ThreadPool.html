    • rejectedExecution

      public void rejectedExecution(Runnable task, ThreadPoolExecutor executor)
      Handles a task that the executor could not assign to a worker. The task is retained in the work queue only while the executor is running and either has reached its maximum size or has an idle worker; otherwise the configured user handler is invoked, or the task is rejected when no user handler is configured.
      Specified by:
      rejectedExecution in interface RejectedExecutionHandler
      Parameters:
      task - the task that could not be assigned to a worker
      executor - the executor that rejected the task
