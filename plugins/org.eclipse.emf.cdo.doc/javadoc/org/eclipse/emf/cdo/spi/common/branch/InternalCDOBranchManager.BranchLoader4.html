public static interface InternalCDOBranchManager.BranchLoader4 extends InternalCDOBranchManager.BranchLoader3
Branch-loader extension that persists branch-tag changes and streams stored tags back to the manager during load. The modification counter lets callers distinguish an update based on stale tag state.
