Interface InternalCDOXASavepoint

All Superinterfaces:
CDORollbackable, CDOUserSavepoint, CDOXASavepoint, InternalCDOUserSavepoint
public interface InternalCDOXASavepoint extends CDOXASavepoint, InternalCDOUserSavepoint
Savepoint representation for a CDO XA transaction. Besides its position in the user-transaction savepoint chain, it retains the set of participating transaction savepoints that must be restored together.
Since:
3.0
Author:
Eike Stepper
No Implement
This interface is not intended to be implemented by clients.
No Extend
This interface is not intended to be extended by clients.
