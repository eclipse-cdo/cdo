public interface InternalSession extends ISession, CDOIDProvider, CDOPermissionProvider, CDOCommonSession.Options, org.eclipse.net4j.util.concurrent.IExecutorServiceProvider, org.eclipse.net4j.util.collection.Entity.Store.Provider
Server representation of one connected client session. It owns that client's views and protocol, supplies ID and permission context for requests, and projects repository notifications—including ordered lock changes—into the state visible to that client.
Since:
4.3
Author:
Eike Stepper
No Implement
This interface is not intended to be implemented by clients.
No Extend
This interface is not intended to be extended by clients.
