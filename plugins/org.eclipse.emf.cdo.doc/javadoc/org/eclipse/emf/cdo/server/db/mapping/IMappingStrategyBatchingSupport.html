Interface IMappingStrategyBatchingSupport

public interface IMappingStrategyBatchingSupport
Optional bulk-write extension for IMappingStrategy.

A strategy implementing this interface receives one complete DBStore write phase. It may partition the work among class mappings. Implementations that do not provide this extension retain the existing single-item behavior.
