Interface IAppExtension

All Known Subinterfaces:
IAppExtension2, IAppExtension3, IAppExtension4, IAppExtension5
All Known Implementing Classes:
AbstractAppExtension, AppExtension, LMAppExtension
public interface IAppExtension
Lifecycle hook for server application extensions loaded from an application configuration file. The server starts the extension with that file and later calls it to release any resources it acquired.
