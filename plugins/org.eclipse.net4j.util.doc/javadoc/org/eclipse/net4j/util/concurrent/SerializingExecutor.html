Class SerializingExecutor

All Implemented Interfaces:

public class SerializingExecutor extends Lifecycle implements Executor, Runnable
An executor that runs submitted tasks one at a time, in the order in which they are queued, using a delegate executor. The delegate remains externally owned. Before the first activation, execute(Runnable) and all submit methods retain tasks until activation. After deactivation, execute(Runnable) continues to retain tasks until a later activation, while submit rejects new tasks. Tasks that were queued when deactivation begins are discarded, and their submitted futures are cancelled.

      Queues a task for serial execution and returns a future that completes when the task completes. Before the first activation, the task is retained until activation. After deactivation, this method rejects the task.
