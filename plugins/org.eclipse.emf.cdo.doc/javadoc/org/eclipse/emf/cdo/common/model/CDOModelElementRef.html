public interface CDOModelElementRef<T extends EModelElement> extends Serializable
A symbolic reference to an EMF model element.

The reference contains only the symbolic identity of its model element. It does not retain a package registry and does not resolve anything as a side effect of construction, comparison, hashing, or serialization. Resolution is performed explicitly by resolve(EPackage.Registry).
