public abstract class RepositoryUserManager extends org.eclipse.net4j.util.lifecycle.Lifecycle implements org.eclipse.net4j.util.security.IUserManager, org.eclipse.net4j.util.security.IAuthenticator
Repository-scoped source of user credentials that also authenticates clients against those credentials. The managed container injects the repository context so subclasses can retrieve a user's password from the repository they serve.
