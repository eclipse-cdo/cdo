Class CDOCollectionLoadingConfig

java.lang.Object
org.eclipse.emf.cdo.common.revision.CDOCollectionLoadingConfig
public final class CDOCollectionLoadingConfig extends Object
An immutable collection-loading configuration snapshot.

A null configuration means that modern partial collection loading is disabled. A non-null configuration, including an empty configuration, enables the mode. The configuration itself only describes runtime defaults and explicit model-element overrides; it does not evaluate metamodel annotations or perform collection loading.
