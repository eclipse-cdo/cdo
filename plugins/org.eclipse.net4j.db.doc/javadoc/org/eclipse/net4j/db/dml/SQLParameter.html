Interface SQLParameter

All Superinterfaces:
SQLExpression, SQLOrderItem, SQLSelectItem
public interface SQLParameter extends SQLExpression
An immutable logical parameter identity. Reusing one instance in a definition represents multiple JDBC placeholder occurrences that can be bound together by identity. SQL.param(int) supplies an explicit JDBC type for typed NULL values and typed setObject; otherwise NULL uses the field type inferred for each occurrence and translated by the adapter used during compilation. A converter runs once per occurrence for each non-null input value. Null input bypasses the converter and follows typed SQL NULL binding. A specialized binder supplied to SQLStatement takes precedence over conversion and default setters and receives the original input. Converter exceptions propagate to the binding caller, and converted values are never stored on the parameter or compiled statement.
