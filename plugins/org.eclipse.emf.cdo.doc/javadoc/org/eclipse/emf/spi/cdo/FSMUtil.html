Class FSMUtil

java.lang.Object
org.eclipse.emf.spi.cdo.FSMUtil
public final class FSMUtil extends Object
Internal bridge between the public CDOObject model and the CDO state machine. It adapts legacy EMF objects to their CDO wrappers and exposes state checks used by view and transaction implementation code.
Since:
4.0
