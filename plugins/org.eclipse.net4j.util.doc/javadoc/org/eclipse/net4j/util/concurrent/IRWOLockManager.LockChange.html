Enclosing interface:
IRWOLockManager<OBJECT,CONTEXT>
public static final class IRWOLockManager.LockChange<OBJECT> extends Object
An immutable request to lock or unlock objects for one context. A null object collection means all objects owned by the context and is valid only for an IRWOLockManager.LockChange.Operation.UNLOCK change. For unlock changes, a null lock type means all lock types and IRWOLockManager.ALL_LOCKS means all lock counts.
