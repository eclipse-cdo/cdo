Interface InternalCDOWorkspaceBase

All Superinterfaces:
CDORevisionProvider, CDOWorkspaceBase, CDOWorkspaceBase2
public interface InternalCDOWorkspaceBase extends CDOWorkspaceBase2
Internal contract for a workspace base that tracks object additions, changes, and detachments while a workspace transaction is committed or cleared. The workspace implementation uses these operations to keep its local base store consistent.
Author:
Eike Stepper
No Implement
This interface is not intended to be implemented by clients.
No Extend
This interface is not intended to be extended by clients.
