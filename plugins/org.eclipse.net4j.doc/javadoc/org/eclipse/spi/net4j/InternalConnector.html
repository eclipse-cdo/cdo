public interface InternalConnector extends IConnector, org.eclipse.net4j.util.security.INegotiatorAware, InternalChannelMultiplexer
Internal connector contract that combines the public connector API with channel multiplexing and negotiator configuration. Net4j connector implementations use it to expose the transport-level operations needed by the framework.
