Interface SQLSelectSourceStep

All Superinterfaces:
SQLBuildStep, SQLSelectBuildStep
All Known Subinterfaces:
SQLSelectFromStep, SQLSelectJoinedStep
public interface SQLSelectSourceStep extends SQLSelectBuildStep
A SELECT stage with a source clause and optional further clauses. Repeated FROM additions create comma-separated sources when there are no joins. If joins follow multiple FROM sources, the compiler combines those initial sources with CROSS JOIN and groups them as the left operand; subsequent joins associate left-to-right. Arbitrary explicit join-tree nesting is not supported.
