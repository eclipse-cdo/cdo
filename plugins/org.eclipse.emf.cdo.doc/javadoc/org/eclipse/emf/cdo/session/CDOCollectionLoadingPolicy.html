Interface CDOCollectionLoadingPolicy

All Superinterfaces:
CDOListResolver
@Deprecated public interface CDOCollectionLoadingPolicy extends CDOListResolver
Deprecated.
As of 4.31 use CDOCollectionLoadingConfig. Legacy execution methods are no longer supported and policies overriding them are rejected when installed in a session.
A legacy strategy that specifies which list elements must be present (loaded) in a CDOID list of a revision when a certain list index is accessed. Implementations of this interface can control the exact characteristics of a certain partial collection loading strategy.
Since:
2.0

    • getInitialChunkSize

      @Deprecated default int getInitialChunkSize(CDORevision revision, EStructuralFeature feature)
      Deprecated.
      As of 4.31 legacy policy API; use CDOCollectionLoadingConfig.
      Returns the maximum number of CDOIDs to be loaded initially for the given many-valued feature. The default implementation preserves the revision-independent policy represented by getInitialChunkSize().

      Current revision loading requests carry one initial chunk size for the complete revision. Consequently, this feature-aware form is available for policy composition and future per-feature initial loading, but it is not used to split a single revision request into different initial chunks.

      Parameters:
      revision - the revision that owns the feature
      feature - the many-valued feature
      Returns:
      the maximum number of initially loaded elements
      Since:
      4.30
