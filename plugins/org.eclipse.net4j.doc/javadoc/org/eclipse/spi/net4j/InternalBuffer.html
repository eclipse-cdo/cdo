Interface InternalBuffer

All Superinterfaces:
IBuffer
public interface InternalBuffer extends IBuffer
Internal buffer contract for storage that can be associated with a provider and terminally disposed.

IBuffer.release() relinquishes the current lease and may return storage to the associated provider for reuse. dispose() ends the storage lifetime permanently; a disposed buffer cannot be cleared or reused. External buffers can implement IBuffer without implementing this internal pooled-storage contract.
