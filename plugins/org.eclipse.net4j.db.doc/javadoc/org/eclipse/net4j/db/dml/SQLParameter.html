Interface SQLParameter

All Superinterfaces:
SQLExpression, SQLOrderItem, SQLSelectItem
public interface SQLParameter extends SQLExpression
An immutable logical parameter identity. Reusing one instance in a definition represents multiple JDBC placeholder occurrences that can be bound together by identity. SQL.param(int) supplies an explicit JDBC type for typed NULL values and typed setObject; otherwise NULL uses the field type inferred for each occurrence and translated by the adapter used during compilation. A parameter may have no strategy, a converter, or a SQLValueSetter; converters and setters are mutually exclusive configurations. Converters run once per occurrence for each non-null input and their results use standard JDBC binding. Null input bypasses converters and follows typed SQL NULL binding. A setter owns the complete JDBC operation and receives the original input, including null. Call-specific setter and converter overrides replace the configured strategy for that binding operation only. Converter exceptions propagate, and converted values are never stored on the parameter or compiled statement.
