      public final org.eclipse.net4j.util.registry.IRegistry<String,Object> properties()
      Returns this element's properties registry.

      The registry is created lazily on first access. If this element's repository protector provides a ScopedRegistry.Store, the registry shares that store with other elements of the protector. Otherwise, an independent registry is used. The returned registry is stable for the lifetime of this element.
