Interface SQLInsertStartStep

public interface SQLInsertStartStep
An INSERT target offering three alternative forms: values in schema field order, an explicit column list followed by positional values, or explicit named assignments. These forms cannot be mixed in one INSERT; column/value counts are checked during compilation.
Since:
4.15
Author:
Eike Stepper
No Implement
This interface is not intended to be implemented by clients.
No Extend
This interface is not intended to be extended by clients.

    • columns

      SQLInsertColumnsStep columns(IDBField first, IDBField... others)
      Selects explicit target columns and returns a stage that requires positionally corresponding values. This form is an alternative to implicit schema-order values and named assignments.
      Parameters:
      first - the first target column for the INSERT
      others - additional target columns in value order
      Returns:
      the next valid fluent stage
      Since:
      4.15

    • values

      SQLInsertValuesStep values(SQLExpression first, SQLExpression... others)
      Supplies values for the INSERT target. Without an explicit column list, values correspond to schema fields in field order; after columns(...) they correspond positionally to that list. Counts are validated during compilation.
      Parameters:
      first - the first expression value
      others - additional values in matching column order
      Returns:
      the next valid fluent stage
      Since:
      4.15

    • set

      SQLInsertAssignmentStep set(IDBField column)
      Begins an explicit named INSERT assignment. Named assignments avoid relying on implicit target-column order and cannot be mixed with columns(...) or values(...).
      Parameters:
      column - the existing schema column
      Returns:
      the next valid fluent stage
