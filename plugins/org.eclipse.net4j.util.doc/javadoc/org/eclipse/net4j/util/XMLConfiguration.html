Class XMLConfiguration

java.lang.Object
org.eclipse.net4j.util.XMLConfiguration
public final class XMLConfiguration extends Object
A finalized, immutable snapshot of an XML document. Set parameters before calling prepare(File) or prepare(Reader). Preparation uses a namespace-aware, secure parser, preprocesses conditional elements, expands retained element attributes, and records metadata on the resulting DOM nodes. The prepared document is fixed: later parameter or converter changes do not alter its values.

Parameter keys are replaced literally wherever they occur in attribute values. The standard keys are @user, @state, and @config; callers may add or replace keys before preparation. Values are expanded with StringUtil.replace(String, Map) and then passed through registered StringConverters. Conditions are evaluated before ordinary attribute expansion. See XMLUtil.preprocessConditions(org.w3c.dom.Document, Map) for condition syntax.

getDocument() returns a defensive DOM copy. Its expanded-state metadata is copied with the nodes so that downstream processors can distinguish finalized values from values in an unprocessed document. This allows multiple consumers to inspect the same snapshot without sharing mutable DOM nodes. File-backed configurations retain their source file; Reader-backed configurations do not have a source file.

Parsing rejects DTD declarations and disables external entities, XInclude, and entity expansion. Namespace-free XML documents remain valid. For example: 

<configuration>
  <service endpoint="@endpoint" enabled="true"/>
</configuration>
