      void recordDiagnosticCounter(String name, long value)
      Adds a value to an optional mapping-specific diagnostic counter.

      Counter names and values are diagnostic metadata only. They do not participate in statement scheduling, execution ordering, or batching decisions.

      Parameters:
      name - the short counter name
      value - the value to add
