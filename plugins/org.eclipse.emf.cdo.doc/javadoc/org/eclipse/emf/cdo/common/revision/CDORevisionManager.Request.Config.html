Class CDORevisionManager.Request.Config

java.lang.Object
org.eclipse.emf.cdo.common.revision.CDORevisionManager.Request.Config
Enclosing interface:
CDORevisionManager.Request
public static final class CDORevisionManager.Request.Config extends Object
Immutable loading options shared by revision manager operations and modern revision loaders. The configuration is intentionally a superset: an operation or loader ignores options that it does not support. The collection policy is retained by reference, so concurrent reuse of a configuration also requires that policy implementation to be thread-safe.
