Class CDOSessionProtocol.RefreshSessionResult

java.lang.Object
org.eclipse.emf.spi.cdo.CDOSessionProtocol.RefreshSessionResult
Enclosing interface:
CDOSessionProtocol
public static final class CDOSessionProtocol.RefreshSessionResult extends Object
Contains the repository update position and package-unit information returned when a session refreshes. The client uses this snapshot to synchronize its views with repository changes that have occurred since its previous update.
Since:
3.0
