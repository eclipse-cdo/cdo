Interface SQLCondition

All Superinterfaces:
SQLExpression, SQLOrderItem, SQLSelectItem
public interface SQLCondition extends SQLExpression
A boolean SQL expression that can also be projected or ordered when supported by a dialect. Conditions created with and(SQLCondition) and or(SQLCondition) retain their explicit tree structure; the compiler adds parentheses where needed. By contrast, connector calls in a fluent WHERE, HAVING, or JOIN ON clause follow SQL operator precedence, where AND binds more tightly than OR. Use complete composed conditions when a particular grouping is required. Comparisons to SQL NULL are not rewritten; use SQL.isNull(SQLExpression) or SQL.isNotNull(SQLExpression) for SQL NULL tests.
