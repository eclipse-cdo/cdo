Interface SQLInStep<NEXT>

Type Parameters:
NEXT - the statement stage available after the list is completed
public interface SQLInStep<NEXT>
An incomplete value list embedded in a fluent comparison stage. The enclosing statement remains incomplete until end() records a non-empty list and returns its normal continuation.
Since:
4.15
Author:
Eike Stepper
No Implement
This interface is not intended to be implemented by clients.
