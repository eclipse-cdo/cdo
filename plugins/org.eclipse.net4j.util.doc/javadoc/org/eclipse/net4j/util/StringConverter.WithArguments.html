@FunctionalInterface public static interface StringConverter.WithArguments extends StringConverter
A StringConverter that accepts parsed argument arrays while retaining direct invocation through apply(Object). StringUtil passes structured arguments to this interface without flattening them. A direct String invocation splits on unescaped commas and resolves $ escapes; a direct String array is passed to applyArguments(String[]) unchanged. A null direct value is passed as null to applyArguments(String[]).
