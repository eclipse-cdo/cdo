Interface InternalQueryResult

All Superinterfaces:
BlockingCloseableIterator<Object>, org.eclipse.net4j.util.collection.Closeable, org.eclipse.net4j.util.collection.CloseableIterator<Object>, Iterator<Object>
public interface InternalQueryResult extends BlockingCloseableIterator<Object>
Server-side result stream for a query executing against a view. The query manager exposes it as a blocking iterator backed by a queue, while retaining the handler and query metadata needed for cancellation and lifecycle management.
