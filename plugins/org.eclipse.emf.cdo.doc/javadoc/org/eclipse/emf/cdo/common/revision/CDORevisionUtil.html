    • createChangeSet

      public static CDOChangeSet createChangeSet(CDOBranchPoint startPoint, CDOBranchPoint endPoint, CDOChangeSetData data, CDORevisionProvider startRevisionProvider)
      Creates a change set and retains the complete revisions at its start point for consumers that must interpret executable feature deltas against their actual common base.
      Parameters:
      startPoint - the coordinate at which the histories start.
      endPoint - the coordinate reached after applying the histories.
      data - the change-set data.
      startRevisionProvider - the provider of full start revisions.
      Returns:
      a change set retaining the supplied start-revision context.
      Since:
      4.28
