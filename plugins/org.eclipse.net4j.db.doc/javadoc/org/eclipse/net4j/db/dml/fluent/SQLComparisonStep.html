Interface SQLComparisonStep<NEXT>

Type Parameters:
NEXT - the stage available after the comparison is completed
public interface SQLComparisonStep<NEXT>
The right-hand comparison stage. Completing an operator returns the enclosing clause stage. Equality and ordering comparisons retain SQL NULL semantics; use isNull() or isNotNull() to test for NULL explicitly.
Since:
4.15
Author:
Eike Stepper
No Implement
This interface is not intended to be implemented by clients.
No Extend
This interface is not intended to be extended by clients.
